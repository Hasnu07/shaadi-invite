# Daniyal & Mahnoor · Shaadi invite

A digital wedding invitation: a wax-sealed envelope that opens onto gilt-framed slides for each function,
with Urdu, Hijri dates, little games on every page and a WhatsApp RSVP.

**Live:** https://hasnu07.github.io/shaadi-invite/

## Editing

Everything about the wedding (names, families, dates, venues, programmes, WhatsApp numbers) lives in the
`INVITE` block near the top of the script in `index.html`. Change it there and the whole invite updates.

The background music is `music.mp3`, looped. Delete that file and the invite plays a built-in ambient raag instead.
